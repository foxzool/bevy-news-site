### 合并 — 8
- ⭐ [#25923](https://github.com/bevyengine/bevy/pull/25923) Add local editing to the inspector details panel（A-Dev-Tools, M-Release-Note）：详情面板可编辑选中实体的组件字段（bool/数值/字符串/char/unit enum），经 `FieldEdit` 事件与反射写回。
- ⭐ [#26014](https://github.com/bevyengine/bevy/pull/26014) Add a remote source to the inspector entity tree（A-Dev-Tools, D-Complex, M-Release-Note）：经 Bevy Remote Protocol 把远程 `World` 镜像到 `RemoteWorld`，实体树可查看另一进程的游戏世界。
- ⭐ [#25987](https://github.com/bevyengine/bevy/pull/25987) Add feathers styling for tabs（A-UI, M-Release-Note）：为 headless tabs 加上 Feathers 编辑器风格与拖拽幽灵/落点指示。
- [#26056](https://github.com/bevyengine/bevy/pull/26056) Support arrays of BsnValue as a BsnFnArg (adopted)（A-Scenes, D-Modest, milestone 0.20）：BSN 函数参数支持实体引用数组（采纳自 #25942），解除 `bevy_enhanced_input` 等场景的阻塞。
- [#26048](https://github.com/bevyengine/bevy/pull/26048) Fix `replace_related` allowing duplicate entities（A-ECS, milestone 0.20）：`replace_related` 先经 `EntityHashSet` 去重，避免误插入重复实体。
- [#26060](https://github.com/bevyengine/bevy/pull/26060) Allow pressing `NumpadEnter` to confirm values in Feathers number input and color input controls（A-UI, C-Usability）：数字/颜色输入同时接受 Enter 与 NumpadEnter。
- [#26025](https://github.com/bevyengine/bevy/pull/26025) Keep the resize cursor while dragging the inspector column splitter（A-UI, A-Dev-Tools）：列分割条拖拽时捕获指针，保持 resize 光标。
- [#26037](https://github.com/bevyengine/bevy/pull/26037) Some crate uniformization（A-Meta, C-Code-Quality）：补 license、统一 docs.rs flags 等 crate 元数据。

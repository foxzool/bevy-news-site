### 合并 — 20（非 trivial 14，trivial 6）
- ⭐ [#25653](https://github.com/bevyengine/bevy/pull/25653) Incremental UI layout updates（C-Performance, A-UI, M-Migration-Guide, M-Release-Note, D-Complex）：`bevy_ui` 布局改为增量更新。删掉 `UiSurface` 里单独维护的 `TaffyTree`，新的 `UiLayoutTree` 适配器让 Taffy 直接读 ECS 组件；`ComputedNode` 只在布局输入变化时更新；`ui_layout_system` 拆成 6 个系统；`GhostNode` 去掉 feature gate，常开并要求 `Node`。fixes #25150，35 个文件 +5724/−4009。
- ⭐ [#26043](https://github.com/bevyengine/bevy/pull/26043) BSN: file format lexing, parsing, and AST（C-Feature, A-Scenes, D-Complex, X-Blessed, milestone 0.21）：新 crate `bevy_bsn`（feature `bevy_bsn`），用 nom 做词法、手写递归下降解析 `.bsn` 文件并产出 AST，是 BSN 文件资产加载器的第一块。
- ⭐ [#25953](https://github.com/bevyengine/bevy/pull/25953) Support `KHR_meshopt_compression` and `EXT_meshopt_compression` in bevy_gltf（C-Feature, A-glTF）：新 feature `gltf_meshopt`，加载时把压缩的 buffer view 解码进 fallback buffer；没开 feature 时加载要求该扩展的文件会警告并点名 feature。
- [#25954](https://github.com/bevyengine/bevy/pull/25954) Support `KHR_mesh_quantization` in bevy_gltf（C-Feature, A-glTF）：量化的位置、法线、切线、UV 和 morph target 在加载时反量化为浮点。
- ⭐ [#25809](https://github.com/bevyengine/bevy/pull/25809) Mutable `NestedQuery` with wrapper that erases `QueryData` type（C-Feature, A-ECS, D-Complex, D-Unsafe）：`NestedQuery` 支持可变查询，State 改存 `QueryState<D::ReadOnly, F>`，外包 `ErasedQueryState` 防止误取内部状态。
- [#26034](https://github.com/bevyengine/bevy/pull/26034) Add a dock tree data model to bevy_ui_widgets（C-Feature, A-UI, A-Editor, M-Release-Note）：新 `dock` 模块，`DockTree` 组件用纯数据描述 tab 组与带权重的分割，支持加/拆/移/关 tab，`serialize` feature 下可保存恢复；UI 部分后续再做。
- [#26063](https://github.com/bevyengine/bevy/pull/26063) Add color and enum variant editing to the inspector（C-Feature, A-Dev-Tools, M-Release-Note）：inspector 详情面板可用取色器 + hex 输入改颜色字段；带数据的 enum（含 `Option`）可切换 variant，新 variant 用已注册的 `Default` 构造。
- [#26172](https://github.com/bevyengine/bevy/pull/26172) Include type paths in component inspection results（C-Bug, A-Reflection, A-Dev-Tools）：`ComponentInspection`、`ComponentTypeMetadata` 加 `type_path`，直接进入 BRP 响应，为 schema 驱动的远程 inspector 铺路。
- [#26162](https://github.com/bevyengine/bevy/pull/26162) Order and index fields in BRP registry.schema（A-Dev-Tools）：`registry.schema` 属性按名排序并带 `fieldIndex` 声明顺序，`reflectTypes` 排序，属性上误填字段名的 `typePath` 键移除；附迁移文但未打 M-Migration-Guide 标签。
- [#26096](https://github.com/bevyengine/bevy/pull/26096) Make bevy_audio an optional dependency of bevy_dev_tools（A-Audio）：`bevy_dev_tools` 不再无条件拉 `bevy_audio`（以及 Linux 上的 ALSA），改为默认关闭的 `bevy_audio` feature；用 `DefaultPlugins` 默认 feature 的项目不受影响。
- [#26099](https://github.com/bevyengine/bevy/pull/26099) Add settings support for color input preferences（A-UI, A-Editor）：Feathers 的 `ColorInputSettings` 接入 `bevy_settings`，颜色输入模式和最近颜色可保存恢复。
- [#26150](https://github.com/bevyengine/bevy/pull/26150) Hook up number input step chevrons（C-Bug, A-UI）：fixes #26124，Feathers 数字输入框的上下箭头按 `NumberInputStep` 步进，遵守 `HardLimit` 与 `NumberInputWrap`。
- [#26004](https://github.com/bevyengine/bevy/pull/26004) Subtract the viewport origin from the pointer position in `update_drag_proxies`（C-Bug, A-UI）：拖拽代理的指针位置减去相机 viewport 偏移。
- [#26084](https://github.com/bevyengine/bevy/pull/26084) Support ViewportNode in BSN（A-UI, A-Scenes）：`ViewportNode` derive `Default` 与 `FromTemplate`，可写进 `bsn!`。

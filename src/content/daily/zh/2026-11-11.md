**UI — Val、文本输入与视口**
- ⭐ [#26415](https://github.com/bevyengine/bevy/pull/26415) **`Val` reorganisation**（ickshonpe；A-UI / C-Code-Quality / M-Migration-Guide / D-Straightforward；12 files，+1085/−1266）。从 calc PR #26409 拆出：`LayoutContext` 更名为 `ValContext`；`Val` / `Val2` / `UiPosition` / `CornerRadius` / `RadialGradientShape` / `BorderRadius` 的 `resolve` 以及 `UiTransform::compute_affine` 改收 `&ValContext`（百分比基准尺寸仍单独传入）。`Val*` 与 `px` / `percent` 等构造函数迁到新 `val` 模块，仍从 `bevy::ui` 与 prelude 再导出。官方迁移文 `val_reorganization.md`。
- ⭐ [#26416](https://github.com/bevyengine/bevy/pull/26416) **New non-numeric `Val` variants**（ickshonpe；C-Feature / A-UI / D-Straightforward；4 files，+93/−18）。新增 `MinContent`、`MaxContent`、`FitContent`、`Stretch`、`Content`（对齐 Taffy `CompactLength`）；仅 `Node` 的 `width` / `height` / `flex_basis` 支持（`Content` 仅 `flex_basis`），其余上下文当作 `Auto`。穷尽匹配需补变体。附迁移文 `new_val_variants.md`，但 PR **无** M-Migration-Guide 标签。
- ⭐ [#25117](https://github.com/bevyengine/bevy/pull/25117) **Password-style character masking for editable text inputs**（Cyannide；C-Feature / A-UI / M-Migration-Guide / M-Release-Note；里程碑 0.21；8 files，+837/−21）。`EditableText::mask: Option<char>` 只影响显示；`value()` 始终返回真实输入。结构体字面量需 `..default()` 或显式补 `mask` / `mask_state`。官方迁移文 `editable_text_mask.md`。
- ⭐ [#25110](https://github.com/bevyengine/bevy/pull/25110) **Placeholder text for editable text inputs**（Cyannide；C-Feature / A-UI / A-Text / M-Release-Note / D-Complex；里程碑 0.21；7 files，+451/−69）。新组件 `Placeholder`（位于 `bevy_text`，与 `EditableText` 为邻）：模式 `WhileEmpty` / `UnlessFocused`；hint 不进入 editor buffer，故 `value()` / IME / 选择仍见空内容。可与 #25117 叠加（可见性看 editor 是否为空）。尚无 accessibility hint 属性。
- ⭐ [#26465](https://github.com/bevyengine/bevy/pull/26465) **Fix viewport node sizing regression**（rossleonardy；C-Bug / A-UI / I-Regression / M-Migration-Guide / D-Straightforward；里程碑 0.21；3 files，+114/−62）。Taffy 升级（#25413 / taffy#960）后隐式视口节点拿到 `auto` 行列轨道，列会随内容撑开而不再锁 100% 视口。现用 `minmax(0, 1fr)` 轨道。`VIEWPORT_NODE_TAFFY_STYLE` 改为私有，改走 `TaffyStyle::viewport_node()`。官方迁移文 `implicit_viewport_node.md`。
- [#26468](https://github.com/bevyengine/bevy/pull/26468) **Set Text input cursor color when input initialize**（DiaboloAB；C-Bug / A-UI / D-Straightforward；1 file，+16/−0）。Feathers 新建文本输入的光标未应用主题色；新增 `update_text_cursor_color_spawned`（`Added<FeathersTextInput>`）。

**Dev-Tools / Inspector / BRP**

- ⭐ [#26462](https://github.com/bevyengine/bevy/pull/26462) **Brp deferred handler, used for input BRP methods**（mockersf；C-Feature / A-Dev-Tools / C-Testing / M-Migration-Guide；里程碑 0.21；7 files，+593/−304）。BRP 可在收到请求的**不同帧**再回复（类似 watch 但只回一次）；输入方法等全部事件发出后再返回，内部改用动作间隔而非绝对帧号。`RemoteMethodSystemId` → `RemoteMethodHandler`（`.register(world)`）。HTTP 传输对 watching 方法改走 SSE，不再靠方法名含 `+watch`。官方迁移文 `brp_deferred_methods.md`。

### 合并 — 8（非 trivial 4，trivial 4）
**UI / Text**
- ⭐ [#26183](https://github.com/bevyengine/bevy/pull/26183) Dock UI：标签页可在分组间拖动（jbuehler23；C-Feature / A-UI / D-Complex / X-Uncontroversial；9 files，+2024/−15）。`DockPlugin` 并入 `UiWidgetsPlugins`，按 #26034 的 `DockTree` 数据模型生成 UI：每个 split 是带手柄的 `SplitPane`，每个分组是 `TabList` + 内容区；面板内容按 `DockPanelKey` 在 `DockPanels` 注册，切换或移动标签时状态保留。跨组拖放变成 `DockEdit::MoveTab`，空组自动移除。无头控件，只管布局不管颜色；新 `ui/widgets/dock` example。拖到边缘拆分组的 drop zone 留给下一个 PR（追踪 #25958）。
- [#26483](https://github.com/bevyengine/bevy/pull/26483) NoWrap 文本跳过容器宽度变化的重排（lvyaqiao；C-Performance / A-UI / A-Text；2 files，+180/−3）。`NoWrap` 用无界约束，节点宽度变化不影响字形布局，所以节点变化触发只留给换行文本；文本本身变化与 font hinting 更新路径不变。无新公共 API，附 3 个回归测试。

**Rendering**
- ⭐ [#26482](https://github.com/bevyengine/bevy/pull/26482) Wireframe cull mode（tychedelia；C-Feature / A-Rendering / M-Release-Note / X-Uncontroversial；4 files，+93/−11）。新增 `WireframeConfig::cull_mode: Option<Face>`，默认 `Some(Face::Back)`，行为不变；`None` 画出所有面的边，不必再开 x-ray（x-ray 会关掉深度测试）。值进 wireframe pipeline key，改动会重新特化；`Face` 获得 opaque `Reflect` impl。`wireframe` example 按 `K` 切换。
- [#26335](https://github.com/bevyengine/bevy/pull/26335) 避免 PBR shader 产生 NaN（tiesselune；C-Bug / A-Rendering；5 files，+11/−11）。法线几乎平行视线时 `VdotH` / `NdotV` 因 f32 误差略大于 1，`F_Schlick` 里 `pow(1.0 - VdotH, 5.0)` 得到 NaN，经 Bloom 扩散成白闪（WebGL2 / WebGPU，0.18 起就有）。`F_Schlick` 改用 `saturate`，源头 `max` 改 `clamp`；涉及 deferred lighting、pbr_fragment / functions / lighting、SSR。

**ECS / Build（trivial）**
- [#26517](https://github.com/bevyengine/bevy/pull/26517) 删除 `bevy_ecs::never` 模块，`Never` 别名全部换成已稳定的 `!`，MSRV 升到 **1.100.0**（kpreid；D-Trivial；6 files，+7/−48）。作者说按理该写迁移指南，但未加 M-Migration-Guide。
- [#26518](https://github.com/bevyengine/bevy/pull/26518) CI Rust 升到 1.100（mockersf；D-Trivial）。
- [#26492](https://github.com/bevyengine/bevy/pull/26492) `impl Mul<Val> for f32`，`10. * px(10)` 也能写（ickshonpe；D-Trivial / A-UI）。

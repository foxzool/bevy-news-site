### 合并 — 3
- ⭐ **#26538 Reflect2: custom attributes**（cart，A-Reflection，C-Feature）：重写中的 `bevy_reflect2` 支持 custom attributes，语法与 `bevy_reflect` 相同（`#[reflect(@Tooltip("A widget"))]`、字段上 `@Range(0.0, 1.0)`）；区别是属性存在 `Type` 上的 const 兼容数组里（稳定版 Rust 暂不能在 const 上下文读取）。补上 11-07 MVP（#26356）刻意留空的一项；`#[info(...)]` 简写另开 PR。+442/−39。
- ⭐ **#26526 WASM: Fit canvas to parent by default**（Runi-c，A-Windowing，O-Web，M-Migration-Guide，X-Contentious）：`Window::fit_canvas_to_parent` 默认改为 `true`。理由：在 itch.io 等常见 HTML 加载页上，不开此项全屏按钮无效，是发布 Web 版时最常踩的坑；代价是父元素按子元素定尺寸时画布可能无限变大。
- Trivial：#26522 CI 依赖 `peter-evans/create-pull-request` 8.1.1 → 8.1.2（dependabot）。

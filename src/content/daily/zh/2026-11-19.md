**数据源**：GitHub REST API（bevyengine/bevy），check time 2026-11-19T03:54:56Z UTC，merge window 2026-11-18T03:53:25Z → 2026-11-19T03:54:56Z。

### 合并 — 8
- ⭐ **#24609 Adds Box, Gaussian, Kawase and Bokeh Blur**（joelawm，A-Rendering，A-UI，C-Feature，M-Release-Note，0.21）：UI 节点可以把背后的 2D/3D 场景做成磨砂玻璃。相机加 `BlurRegionCamera`（选定 `BlurSetting`），要模糊的节点加 `BlurRegion`。每帧同步可见节点的布局矩形与圆角，作为 UI 之前的后处理；也可经 `blur` / `rounded_blur` 直接推自定义屏幕矩形。四种算法：`Gaussian`（默认，可分离高斯 + 双线性减采样）、`DualKawase`（降采样链，大半径更便宜，强度大致随 `mip_count` 指数增）、`Bokeh`（光圈盘状高光）、`BoxBlur`（盒式，大半径易出条纹）。示例 `cargo run --example blur --features bevy_feathers`。官方 release note `ui_blur_regions.md`。+2008/−0。
- ⭐ **#26559 Add fuzzy search to the inspector entity tree**（jbuehler23，A-Dev-Tools，A-UI，C-Feature，D-Complex，0.21）：实体树上方加过滤盒，用 11-14 入库的 `bevy_fuzzy` 匹配。命中行会展开祖先并高亮匹配字符；组件名也可匹配（不含 `Name`、`ChildOf`、`Children`）。清空过滤会恢复原先展开并露出选中项。远程源可用，结果封顶 500 并提示。应用可通过 `EntityTreeFilter` 设置查询。Feathers 新增 `TEXT_ACCENT` token 做高亮。过滤开启时每次刷新会重扫世界（约 5 万实体 25ms）。属 #23013。+1421/−178。
- **#26607 Send Pointer<Out> and Pointer<Leave> when a hovering pointer is despawned**（Enceladus-py，A-UI，A-Picking，C-Bug，O-Android，O-iOS）：指针实体被销毁时，原先悬停目标收不到 `Pointer<Out>` / `Pointer<Leave>`，会一直保持 hovered。现在记住指针最后位置，销毁时补发事件。修复 #26402。+57/−2。
- **#26496 Solari: Fix black pixels at grazing angles**（JMS55，A-Rendering，C-Bug）：掠射角 BRDF 为 0 会出现黑点；新增 `bend_normal_towards_viewer`，把法线略弯向视线，使 BRDF 非零。修 digitalcortex 复现。+32/−16。
- **#26515 Show enum name for system sets in ambiguity reports**（aniyow07，A-ECS，C-Usability）：歧义报告里枚举 system set 原先只打印变体名（`in set Cleanup`）。新增 `SystemSet::set_type_name()`，必要时拼上类型名，写成 `CombatSystems::Cleanup`。遵循 `use_shortnames`。修 #23908。+105/−3。
- **#26566 Add BevyError::inner and chain**（mrchantey，A-Diagnostics，C-Usability）：`BevyError` 新增 `inner`、`into_inner`、`chain`，可拿到内部 `&dyn Error` 及其 source 链。纯新增，不改现有输出。+91/−1。
- Trivial / 示例：#26354 scrollbars 示例增加横向滚动演示；#26553 Solari 把 temporal reuse 拆成独立 dispatch（D-Trivial；统一 ReSTIR 后融合内核指令过多，RTX 5080 / 3080 上约 6–12% 更快）。

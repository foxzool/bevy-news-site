### 合并 — 14
- ⭐ **#26602 Minimal SVG Loader**（rossleonardy，A-Rendering，A-UI，C-Feature，M-Release-Note，X-Blessed）：开启 `svg` feature（`bevy_feathers` 会带上）后，可用 resvg 把 `.svg` 光栅化成普通 `Image`（`Rgba8UnormSrgb`）。默认按 SVG 自身宽高；也可用 `SvgLoaderSettings` / `SvgRasterSize` 指定 `Scale`、`Width`、`Height` 或 `Fit`，最长边超过 8192 会按比例缩小并警告。`bsn!` 里可像普通图片一样写进 `ImageNode`。不支持 `<text>`、`<image>`、动画与 `<foreignObject>`。这是 #26585 的最小可用切片，完整 SVG 资产类型还在后续 PR。官方 release note `svg_assets.md`。feathers_gallery 加了 logo 示例。+575/−1。
- ⭐ **#26570 Add a visibility toggle to the inspector entity tree**（jbuehler23，A-Dev-Tools，C-Feature，M-Release-Note，D-Modest）：本地实体行末加眼睛图标（Rin / @Atlas16A 绘制，内嵌于 `bevy_inspector`），`Visibility` 为 `Hidden` 时闭眼；点击在 `Hidden` / `Inherited` 间切换，不选中该行，并跟随别处的修改。inspector 自己的 UI 根没有眼睛；远程源尚未拉 `Visibility`，所以远程行也没有。同时修正行高亮：缩进改用 margin，高亮从本行缩进处起，对齐 Figma 设计。长标签会裁切以保住眼睛可见。属 #23013，建在 11-18 #26549 树样式之上。+265/−11。
- **#26593 Reflect2: #[meta] attribute**（cart，A-Reflection，C-Usability）：Reflect2 新增 `#[meta(...)]`，专写元数据，等价于 `#[reflect(@...)]`（`@` 是为了和 reflected traits 区分）。11-17 预告的简写当时叫 `#[info]`，本日落地的名字是 `#[meta]`。同时把「Custom Attributes」术语与 API 改名为 Metadata：`CustomAttributes` → `Metadata`，`CustomAttribute` → `MetadataValue`，模块从 `attributes` 迁到 `metadata`。`#[reflect(@...)]` 仍可用。引擎仍未迁到 Reflect2。+357/−269。
- **#26603 Create `initialize_array_raw` to match `initialize_struct_raw`**（andriyDev，A-Reflection，C-Feature，D-Modest，D-Unsafe）：接 11-18 的 `initialize_struct_raw`，给数组同样的「把元素写入已有指针、不强制分配」路径；调用方只需证明指针可放数组、回调会初始化全部元素。也可用于正确大小/对齐的 `MaybeUninit`。+84/−0。
- **#25523 Optimize moving entity to new table**（JaySpruce，A-ECS，C-Performance，D-Unsafe）：`Tables::move_row`（#23151）再收一刀：每个源列最少只调一次 `next_if`（原先最少两次），且不再把 columns 放进 `Peekable` 迭代器。+66/−57。
- **#26568 Fix `directional_shadow_factor` not working with shadow maps off**（stevesloan，A-Rendering，C-Bug）：材质的 `directional_shadow_factor` 原先只在方向光开了 shadow map 时生效，关图就没效果。现在对所有接收阴影的 mesh 都乘上该因子，shadow map 只在光源带图时再乘进去。+7/−6。
- **#26489 On changes to UiTheme, update children of InheritableThemeTextColor**（cceckman，A-UI，C-Bug，X-Contentious）：改 `UiTheme` 时，经 `InheritableThemeTextColor` 间接上色的文本不会更新。`update_theme` 现在会同步更新这些实体上的 `Propagate<TextColor>`。修 #26488。feathers_gallery 加了暗色/派生主题切换。+64/−2。

### 迁移
- **#26611**（M-Migration-Guide，D-Trivial，官方迁移文 `default_font_size_is_now_rem_1.md`）：`FontSize::default()` 从 `Px(20.)` 改为 `Rem(1.)`。默认 rem 是 20px，所以默认大小的文本看起来仍是 20px。若你改了 `RemSize`，想让这些文本继续保持 20px，需要显式写成 `FontSize::Px(20.)`。

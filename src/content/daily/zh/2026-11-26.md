### 合并 — 11
- ⭐ **#26658 `FontSize::Calc`**（ickshonpe，A-Text，M-Migration-Guide，M-Release-Note，D-Modest）：`FontSize` 新增 `Calc` 变体，可用 `FontSize::calc(|ctx| …)` 按上下文计算结果。官方示例是 `FontSize::calc(|ctx| 5.0 + 0.02 * ctx.view.x)`；PR 说明里也可用 `ctx.vw(2.)` 这类视口单位。实现是 `Calc { calc: FontSizeCalc, scalar: f32 }`，闭包装在 `Arc<Box<dyn Fn(FontSizeCtx) -> f32 + Send + Sync>>` 里，带一个 scalar 以便乘 `f32` 时不必重分配。后果：`FontSize` 不再 `Copy`，体积从 8 字节变为 16 字节。`Calc` 的反射只能看到变体名和 `scalar`，不能从数据重建闭包；序列化会丢掉闭包、反序列化成「始终返回 `RemSize`」的闭包，并打警告。含 calc 的文本在任一上下文值变化时都会重排（看不到闭包依赖了哪些值）。官方 release note `fontsize_calc.md`，官方迁移文 `fontsize_is_no_longer_copy.md`。+143/−14。
- ⭐ **#26353 More UI stack improvements**（ickshonpe，C-Bug，C-Feature，A-Rendering，A-UI，D-Complex，AI-Assisted）：`GhostNode` 支持 `ZIndex` / `GlobalZIndex`，带这些组件时会把后代作为一组堆叠，根 `GhostNode` 可固定其子 UI 根的相对顺序（层级保持兄弟序）。`ZIndex` 不再作为 `Node` 的必选组件（否则会经 require 传到 `GhostNode`，改变原先扁平化的堆叠行为）。移除 `ZIndex` / `GlobalZIndex` 时节点会被提升。`ComputedStackIndex` 内部值改为私有，用 `u32::MAX` 作「不在布局中」的哨兵。无父、非 Ghost 的根节点排序优先级：更高 `GlobalZIndex` → 更高 `ZIndex` → 新根（新生成或刚变成根）在已有根之上 → 自身或后代的 z 值刚变过的在未变之上 → 仍平手则保持上一帧相对顺序。无 M-Migration-Guide。+1731/−210。
- ⭐ **#26626 Solari: World cache improvements**（JMS55，C-Bug，A-Rendering，C-Performance）：修 world cache 一串错误并降低更新成本。校验和改用 Jenkins 并把 cell size 纳入哈希，避免不同 cell 共享 checksum 读到别人的辐射；探测窗口 16 槽全搜（原 3）再插入，键回绕表；只在真实命中点插入、不再用抖动点（原先约 37% 插在几何体内）；每帧更新固定数量的 cell 并打满 warp，把三次 dispatch 合成一次；`world_cache_cell_updates_soft_target` 改名为 `world_cache_max_cell_updates_per_frame`（现为硬上限）；历史按帧而不是按更新次数限制；reset 删除全部 cell（Bistro 上 settle 从 21/89 帧降到 0/7）；compaction 支持 2^10–2^20 任意二次幂 `WORLD_CACHE_SIZE`。作者在 RTX 3080 / Vulkan 上测：Bistro 查找「找不到空槽返回黑」从约 33k/帧降到 0–6；`world_cache` 通道正常帧 0.533 ms → 0.29–0.30 ms，reset 帧 1.84 ms → 0.105 ms。+172/−171。
- ⭐ **#26337 Describe serialized forms of opaque types in BRP schema**（jbuehler23，C-Bug，M-Migration-Guide，A-Dev-Tools，X-Contentious，AI-Assisted，S-Needs-Design）：接 #26308。新增 `SerializedAs` 注解，让 `registry.schema` 用标准 JSON Schema 关键字描述不透明类型的线上形态，避免客户端写死。已标注：`Entity`、`Cow<'static, str>`、`PathBuf`、`SocketAddr`、`AssetPath` 为 string；`Uuid` / `NonNilUuid` 为 `format: "uuid"` 的 string；`NonZero*` 为排除 0 的 integer；`Duration` 为含 `secs`/`nanos` 的 object；`BVec3A` / `BVec4A` 为定长 boolean 数组。其他序列化形态未知的不透明类型标 `rawJson: true`。自有类型可写 `#[reflect(opaque, @SerializedAs::STRING)]`。Rust API：`JsonSchemaBevyType` 新增 `raw_json` 与 `extra`；`TypeSchema::raw_json`。有反射字段但序列化不同的类型（glam 向量、`Name`）暂未覆盖。属 #23013。官方迁移文 `brp_schema_wire_formats.md`。+671/−94。
